# visualTimer
This is a simple web app timer that visualizes time spent working with various images of items you could purchase with the money earned in that time.

To add new items sets:
	- Create a new csv file (itemSets/"itemSetName".csv) and add new item names with correpsonding prices.
	- Create new folder in the images folder (images/"itemSetName"/). Add images here. IMPORTANT: The image names must match the corresponding csv entries.
	- Add "itemSetName" to itemSets/itemSets.json .
